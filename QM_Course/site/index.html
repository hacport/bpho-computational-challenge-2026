Computational Quantum Physics

Everything in this course teaches one thing: how to build the BPhO 2026 Quantum Mechanics entry from an empty file, by yourself. Nothing is assumed. If you have never written a line of Python, start at Chapter 1 and do not skip.

How to use it

Read → type → break → fix. Reading code teaches you almost nothing. Typing it teaches you a little. Breaking it on purpose and fixing it teaches you almost everything. Every chapter has "Break it" exercises — do them.

Never copy-paste in this course. Type every line, even when it is slow. Your fingers learn syntax your eyes skip over.

Exercises are at the end of each chapter; worked solutions live in the solutions/ folder as runnable Python. Try before you look.
