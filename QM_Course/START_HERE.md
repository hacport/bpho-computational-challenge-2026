# Computational Quantum Physics — a course built from your own project

**Author's note.** Everything in this course teaches one thing: how to build the
BPhO 2026 Quantum Mechanics entry sitting in the folder above this one — from an
empty file, by yourself. Nothing is assumed. If you have never written a line of
Python, start at Chapter 1 and do not skip.

---

## How to use this course

**Read → type → break → fix.** Reading code teaches you almost nothing. Typing it
teaches you a little. *Breaking it on purpose and fixing it* teaches you almost
everything. Every chapter has "Break it" boxes — do them.

Keep two windows open: this course on one side, VS Code on the other. Every
chapter has a matching practice file you create yourself.

**Never copy-paste in this course.** Type every line, even when it's slow. Your
fingers learn syntax that your eyes skip over.

at this had the same weeks, they just had them earlier. Keep going.
